# Fit Kaloria — Natural & Premium

Strona demonstracyjna poradni dietetycznej Karoliny Wiaderek w Łodzi.

**Demo:** https://gipsdrill.github.io/fit-kaloria-natural-premium/

## Publikacja
Statyczny HTML/CSS/JS bez procesu budowania i zewnętrznych zależności. GitHub Pages: Deploy from a branch → main → /(root). Wszystkie ścieżki zasobów są względne.

## Treść i źródła
- Dane kontaktowe, kwalifikacje i 12 lat doświadczenia: informacje dostarczone przez zamawiającego; doświadczenie oznaczone jako deklaracja z Facebooka.
- Sześć usług oraz godziny pon.–pt. 8:00–20:00 potwierdzone przez zamawiającego w rozmowie 9 listopada 2026.
- Brak wymyślonych opinii, ocen, liczby pacjentów, cennika i dostępności terminów. Sekcja opinii jawnie oznaczona jako miejsce na przyszłe autentyczne wypowiedzi.
- Dwa portrety Karoliny dostarczone przez zamawiającego. W wersji Natural wycięcie tła zdjęcia w fioletowym garniturze przygotowano narzędziem generowania obrazów.
- Dekoracyjna fotografia żywności wygenerowana na potrzeby projektu; nie przedstawia konkretnej oferowanej potrawy.
- Kompozycja oparta na dostarczonym mockupie.

## Dostępność i prywatność
Semantyczny HTML, polski język, nagłówki, skip link, widoczny fokus, menu z Escape, ograniczenie ruchu prefers-reduced-motion, lokalne obrazy, brak analityki i formularzy medycznych. Kontakt: tel/mailto, gotowe tematy e-mail, kopiowanie adresu. Linki e-mail wymagają skonfigurowanej aplikacji pocztowej.

## Edycja
index.html — treść; style.css — wygląd; app.js — interakcje. Po zmianie domeny zaktualizuj canonical, Open Graph, JSON-LD, sitemap.xml i robots.txt. Nie publikuj opinii bez autentycznego źródła i zgody.
